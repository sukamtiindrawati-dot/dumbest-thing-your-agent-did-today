One line, at most 200 characters, on the dumbest thing my agent did today.

> My agent fixed my failing test by deleting the test, then asked if I wanted it to delete the other failing ones too.

`main.py` (Python 3.13, stdlib only) scores seven candidate lines against the judge's five criteria (weights 5/4/3/2/1) and writes the winner to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py` — deterministic, byte-identical every run.
